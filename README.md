## 🔧 Customization

To customize this website:

1. **Update Contact Information**: Edit the contact section in `index.html`
2. **Modify Colors**: Update CSS variables in `styles.css`
3. **Change Services**: Edit the services grid in `index.html`
4. **Add More Content**: Extend the HTML structure as needed

## 📝 Form Handling

The contact form currently logs submissions to the browser console. To process form submissions:

1. Set up a backend server or use a service like Formspree or EmailJS
2. Update the `handleSubmit` function in `script.js` to send data to your endpoint

## 🌐 Deployment

To deploy this website:

1. **GitHub Pages**: Push to GitHub and enable GitHub Pages in repository settings
2. **Netlify**: Connect your GitHub repository to Netlify
3. **Vercel**: Import the repository to Vercel
4. **Traditional Hosting**: Upload files to your web server via FTP
